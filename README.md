# Local Purple Heart Cape (Fabric, 1.21.11, client-only)
Build: `./gradlew build` (add the Gradle wrapper with `gradle wrapper`) -> `build/libs/localcape-1.0.0.jar`
Drop the jar (plus Fabric API) in `mods/`. Config: `config/localcape.json`. Keybind: Controls > Local Cape.
Swap the texture: replace `assets/localcape/textures/cape.png` (64x32) or override it with a resource pack.
